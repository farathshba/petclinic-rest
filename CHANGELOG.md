## [1.0.0] - 2026-10-15

### Added
- Student-facing README quickstart (run, reset, test, troubleshoot).
- Community files: this changelog, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`.
- `docs/` — architecture overview and a testing guide.
- `exercises/` — self-contained briefs for API testing, performance testing,
  and UI automation, including a Postman starter collection.
- `.github/ISSUE_TEMPLATE` bug-report form and `PULL_REQUEST_TEMPLATE.md`.
- `.gitignore` hygiene for generated test artifacts (Newman, JMeter, Allure).
- `solutions` branch for trainers (kept out of the default student view).

### Baseline
- Forked from [spring-petclinic/spring-petclinic-rest](https://github.com/spring-petclinic/spring-petclinic-rest)
  at upstream commit `afc8fc1` (2026-10-04). Application code is untouched from upstream.

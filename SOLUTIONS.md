# Solutions (trainer-only)

Verified solutions for the [exercises](../tree/master/exercises) live on this
branch. Students: this branch is visible in a public repo — the honour
system applies. Compare only after you have submitted your own work.

Trainers:

- Keep one folder per exercise, mirroring `exercises/<nn>-<topic>/`:
  `exercises/01-api-testing/solution/`, etc.
- Reference solutions in PRs against **this branch**, not `master`.
- For stronger isolation, this branch can be moved to a private repo before
  the event; the student view (`master`) never references it.
